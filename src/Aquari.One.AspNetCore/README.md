# Aquari.One.AspNetCore

ASP.NET Core server-side session adapter.

This is one of the three official Aquari One .NET packages targeting .NET 10.
For installation, API examples, OAuth configuration, and supported scope
availability, see the [official .NET SDK guide](https://docs.aquari.one/sdks/dotnet).

Use `Aquari.One.Server` only on trusted servers. Keep machine keys, webhook
secrets, and confidential OAuth credentials out of public/mobile clients.
Aquari provides identity and trust signals; application-specific roles remain
the responsibility of the consuming application.
